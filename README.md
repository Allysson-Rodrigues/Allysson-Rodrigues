## Engineering Approach

- Clear boundaries beat cleverness.
- Explicit contracts beat implicit behavior.
- Checks should be easy to run and hard to skip.
- AI should accelerate iteration without weakening verification quality.

## AI Workflow

I use AI tools as engineering amplifiers, not as substitutes for review. The goal is faster iteration with smaller diffs, clearer constraints, and explicit validation at each step.

| Layer | Use |
| --- | --- |
| Research | Explore approaches, compare options, and surface risks |
| Planning | Bound scope, define acceptance, and keep changes reviewable |
| Execution | Implement focused diffs, inspect changes, and run local checks |
| Validation | Re-test, challenge risky assumptions, and document tradeoffs |
